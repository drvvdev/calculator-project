# Calculator Project

Консольный калькулятор на Java с историей вычислений и модульными тестами.

## Возможности

- Четыре арифметические операции: сложение, вычитание, умножение и деление.
- Обработка деления на ноль и неизвестных операторов.
- Сохранение последних 10 успешных вычислений.
- Повторение последней успешной операции.
- Обработка некорректного пользовательского ввода.

## Технологии

- Java
- Maven
- JUnit 5
- Git и GitHub

## Команды программы

| Команда | Описание |
|---|---|
| `5 + 3` | Выполнить арифметическую операцию |
| `history` | Показать историю вычислений |
| `last` | Повторить последнюю операцию |
| `clear` | Очистить историю |
| `help` | Показать справку |
| `exit` | Завершить программу |

## Архитектура

Интерфейс `Operation` определяет общий метод `execute()`.

Каждая арифметическая операция реализована в отдельном классе. Класс `Calculator` использует `Map` и `HashMap` для выбора нужной реализации операции по её символу.

Класс `HistoryManager` отвечает за хранение истории вычислений. `Main` обеспечивает взаимодействие с пользователем через консоль.

## Запуск

Для работы необходимы установленный JDK и Maven.

1. Открыть проект в IntelliJ IDEA.
2. Дождаться загрузки зависимостей Maven.
3. Запустить класс `com.drvvdev.calculator.Main`.
4. Вводить выражения в формате `число оператор число`.

## Проверка тестов

В корневой папке проекта выполнить:

`mvn test`

Для проверки используются модульные тесты JUnit 5, покрывающие арифметические операции, историю и обработку ошибок.
